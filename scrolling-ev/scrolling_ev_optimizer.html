Model assumptions & optimization math

State = remaining slots and total added stat. A fresh clean item starts a renewal cycle. Each state permits every enabled scroll, discard/restart, or accept a qualifying item (subject to the finishing rule). A destroyed item receives no recovery. Scroll probabilities are independent and bonuses additive; no slot recovery, pity mechanics, protection, mixed-stat tradeoffs or changing market prices. The calculator assumes unlimited inventory at the input prices.

For each policy we calculate net expected spend C per fresh item attempt, probability P of acceptance, and expected retained stat R (zero for rejected pieces). Repeating independent attempts costs C/P per accepted item, and C/R per retained point. The optimizer minimizes C − λP or C − λR over all reachable states, then searches for the λ where the minimum including the fresh item cost is zero. This finds the global optimal adaptive policy within the model, not a Monte Carlo estimate. Fixed sequences are enumerated if there are at most 100,000 possible sequences; that cap does not restrict the adaptive optimizer.

Guaranteed reference: a selected +1/100% scroll, used across all slots, costs (clean price + slots × scroll price) / slots per added point. Natural stat is not counted in the incremental EV benchmark. Resale recovery is a constant net value for a surviving discarded item, must be below clean price, and defaults to zero.

All calculations run locally. Inputs are saved in this browser when local storage is available.
