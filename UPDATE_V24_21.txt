FM RUSH v24.21 — replacement scanner

The scan controller is replaced with selected-word fast verification plus a
shared English text index for difficult lettering. Visual shape proposals alone never establish identity. Region detection continues during OCR; only the newest queued view is indexed. Positions are checked against the latest frame before publication.
Room-header recognition no longer blocks searching. Current-page targets only;
three-second entry bursts; no idle OCR; found-marker retention is 120 seconds
from detection. Three clearly read, distinctive letters now suffice for CHECK NAME, as requested.
Shared fragments between live sellers require more evidence. Heavy full-scene
OCR detection cannot block room-entry searches.

Use the complete clean ZIP for this transition: older updater code does not
allow the new model file. Keep all model/provenance/license assets together.
No screenshots or videos are included in the clean package. Existing local
purchase records and the current extension protocol are unchanged.

Validation details are recorded in the source tests and benchmark results.
