FM Rush v24.8 — Per-listing screenshot archive — November 14, 2026

NEW:
- On HeneFM Flips /deals, automatically save an actual PNG screenshot of every unique, rendered item card into Downloads/FM_Rush_Item_Screenshots/YYYY-MM-DD/.
- Includes items below the FM Rush 15K/15% alert threshold and sold items if they are displayed by your HeneFM filters.
- Automatically avoids repeated screenshots of the same listing during 1.2-second scans; keeps a rolling 48-hour deduplication history.
- PNG filenames include timestamp, CH, FM, item name, seller IGN, price and listing fingerprint.
- Uses Brave/Chrome DevTools screenshot capture with captureBeyondViewport: true. This captures off-screen DOM cards without scrolling your page.
- Independent asynchronous queue: deal alerts and name-scanning are dispatched first.
- Extension popup has an ON/OFF checkbox, screenshot count, backlog and error display.
- Original 1200ms HeneFM soft refresh, 15K/15% alert filtering, local app, name scanning and OCR are unchanged.

IMPORTANT:
- Brave will ask for new debugger and download permissions when the extension is installed/reloaded. The debugger permission is needed for off-screen PNG screenshots, and Chrome/Brave may display a standard "debugging this browser" banner while screenshots are being captured. Do not keep DevTools attached to the same HeneFM tab, or screenshot capture may fail.
- Screenshots are downloaded to Brave's configured Downloads directory. Disable "Ask where to save each file" in Brave download settings for truly automatic saving.
- Screenshot saving is ON by default. Toggle it OFF in the extension popup to prioritize the absolute lowest overhead.
- Screenshots only cover item cards actually present/rendered in the HeneFM Deals page's DOM; items that the site never displays cannot be captured.
- The archive is local: no screenshot images are uploaded to HeneFM or sent to the FM Rush local app.
- The scanner does not intercept private API calls, change site filters, alter sold status, or guarantee 1.2-second fresh site results.

INSTALL:
1. Extract the ZIP into a new permanent folder.
2. Brave -> brave://extensions -> Developer mode. Remove/disable the older FM Rush extension.
3. "Load unpacked" -> select the new FM_Rush_v24_7/browser_extension directory.
4. Approve new Brave permissions, open/reload https://henefm.com/flips/deals.
5. Click FM Rush's extension icon and ensure "Automatically save each new listing screenshot" is checked.
6. Check Downloads/FM_Rush_Item_Screenshots for dated PNGs. Screenshot queue/failed count/last error appears in the popup.
7. Run START_FM_RUSH.bat for the existing name locator; screenshot saving itself does not require the Windows app.
