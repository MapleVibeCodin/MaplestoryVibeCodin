FM RUSH v24.14 — QUICK SWEEP BEFORE DEEP SEARCHES

Close the old app, extract into a fresh folder, run the top-level
START_FM_RUSH.bat, and confirm v24.14. The extension remains 24.11.0.
Existing local deal archives and the flat Downloads/Bought folder are reused.

The previous first pass could spend several recognition batches on each absent
seller, delaying an obvious shop farther down the room's saved queue.

Now every seller gets a quick strong-candidate check before any deeper recovery:
- Only the two best strong visual proposals reach first-pass OCR.
- Existing exact/confusable name verification is retained.
- Missing or weak names get full recovery on their second attempt.
- Verified names are published immediately, without waiting for the queue.

Scanning still runs only on room entry, channel change, startup inside a room,
or FIND AGAIN. It keeps one OCR thread and the three-second entry deadline.
New arrivals do not restart idle OCR. The BOUGHT screenshot workflow is unchanged.

results include header OCR and simulated 60Hz worker waits, excluding model
startup, Windows capture and overlay drawing. Actual game timing is unverified.
