## Code audit
- Classic Tool: 68 glyph templates, all ten digits, 14px crop, exact atlas tolerance 0; 158x14 name and price cells, 40px row pitch, six rows. Pairwise comparison performed on actual atlas: same-width digit pairs 0/9, 0/8, 0/6, 3/8 differ by five pixels; h/n and v/y by two. No exact duplicate entries in stored atlas. Reject ambiguous glyphs; do not use fuzzy numeric guessing. MIT. Tests assert median glyph <200us, cold shop <5ms, unchanged shop <1ms; not executed here.
- Club FM: actual native glyph, seller, price, tooltip and dual OCR source inspected. Adaptive min RGB mask: bg 80th percentile, fg 1st percentile of left 55%, min contrast 35; dense columns and border masking. Exact price or independent Tesseract/RapidOCR agreement, but missing second quantity accepted when first says one; do not adopt. Tooltip stat arithmetic. 10Hz monitoring, changed-shop limit 900ms, 2–4 reader threads, queue 160; shared mutable glyph state and stale jobs are risks. Published FMWatcher.zip version 2026.11.21.1; publisher SHA256 c17bdf359f16c4ddaf20b61f769f6428c837c28f1c7332cde2ad4ed2e038a7c7, archive size 186595 bytes; ZIP central directory inspected, not independently hashed or executed. License unknown.
- MapleScanner: connected orange buttons, per-cell clipping and blank-gap checks, cursor and own-shop detection, strict price grouping; persistent Tesseract worker, approximate subsampled fingerprint, seller reconciliation, copy/quantity-aware sold sightings. GPL.
- Minerva: rendered price width W=94+11D+4.7C at reference UI scale, +/-5.5px; recalibrate before use. Cannot verify equal-width digit substitutions. Screenshot regression fixtures. MIT.
- mpl-ocr: packed bitmap IoU, baseline alignment, +/-1 pixel shifts and native-font atlas generation. MIT.
- Free Market Tracker: documented 100ms capture, 3 parallel readers, trained OCR, SQLite; recognition implementation paths not retrieved. Lupin: documentation describes capture backpressure and pixel guards. Price Checker: RapidOCR and separate passive scanner code. 
- FM Rush inventory source reviewed: unchanged digest can reuse failed results; proposed expiry for negative results and bounded latest-frame queues. Preserve raw pixel evidence, exact seller, item, quantity, price and strict scroll checks; use shadow native glyph reader on independently labelled historical frames before deployment. No runtime edits, no upstream code executed, no full replay, no 100% accuracy claim.
