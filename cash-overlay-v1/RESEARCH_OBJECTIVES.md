## Governing objective
Evidence-first passive screen research, not just a live rate display. Collect sufficient visible evidence during ordinary play for later questions without asking the user to repeat the same session. Preserve prior captures, raw data and provenance. No game input, game memory reading, external uploads, identification of other players, or public archive of personal screenshots. Use anonymous per-session actor tracks only. No continuous video required (previous user preference). Keep interface simple and processing off the capture-critical path.

## Required outputs and interpretation
1. Map quality: EXP/hour, raw meso pickup/hour, NPC liquidatable value/hour, separately realized wallet change/hour and expense-adjusted cash where measured; kills/hour (own confirmed vs estimated vs map-wide observed), observed spawn/appearance rate/hour as distinct metric. Never label EXP messages as one kill each without attribution/party validation. Separate elapsed vs active rates, observed intervals and missing periods.
2. Personal efficiency: accessible live monster density, idle/unattacked monsters, time since visible appearance, movement/attack/loot/downtime, platform coverage, kill and pickup throughput, reach and distance to monsters, repeated routes and idle opportunities. Distinguish observed screen pixels from map-world coordinates and intended spawn markers.
3. Spawn behavior: species and platform, candidate appearance/disappearance/death timestamps and uncertainty intervals, time between confirmed or probable events, occupancy by region, sustained live-mob accumulation as possible spawn-cap pressure. Compare to public map data dated to patch, intended points and modeled cap/tick; not proof of actual server cap or full-map respawn. Offscreen monsters and unobservable spawns unknown, not zero. Separate appearance via motion/camera scrolling from spawn.
4. Population effect: visible anonymous other players, own party size, observed overlap and competition/cooperation, measured occupancy by platform, map visits with comparable level, gear/skill, time, route and map/channel context where visible. Compare solo versus different population/party configurations. Distinguish visible count lower bound, party size and true map population. No assumption that more players improve or reduce spawn; test matched samples, report uncertainty. Do not infer an offscreen player's position or identity. 
5. Recommendations downstream: identify potentially neglected areas, better standing locations, route changes, map and party comparisons using actual evidence, uncertainty and sample sizes.

## Capture contract (next implementation; not yet delivered)
- Native-resolution full visible game scene every second, timestamp before/at acquisition (monotonic + UTC, sequence, window geometry, acquisition latency, frame gaps and focus/visibility). Hybrid fast JPEG65 4:4:4 scene plus lossless UI crops recommended by measured prior benchmark; dynamically locate crops, store original coordinates, not fixed resolution assumptions. Keep actual codec and dimensions. Preserve periodic full lossless reference frames and additional short bursts around observed activity only if storage/cadence budgets permit; never replace all scene evidence with cropped counters or only record interesting frames.
- Lossless UI evidence: EXP/level/HP/MP, minimap title and map image, visible player markers, party UI, item/meso pickup lines, visible damage and EXP messages when possible, inventory/wallet and visible potion slots. Dynamic UI visibility, crop origin, absent/covered states. Retain raw message observations even when OCR fails. Record distinct per-message timestamps where available, OCR candidates, confidence and rejection reason. Preserve original image references, no double counting.
- Record map and channel only if actually read/visible; job/level/EXP/party/wallet/item counts and last observed timestamps (including unknown/stale states). Record session/map boundaries, activity changes, data gaps, resets, deaths/level-ups, shop/travel time and wallet transfers if visible. Record map identity and screen/map alignment confidence, actor track identifiers only anonymous. Distinguish raw observations from derived metrics; version all extractors and reference datasets.
- Keep raw local frames and sidecars immutable; preserve earlier formats; later replay/analysis writes separate outputs. Manifest sequence, codecs, crop geometry, source links and bytes, per-session quality summary. Storage guard should visibly signal pause and retain older data; no automatic deletion. No background uploads. No guaranteed reconstruction of hidden UI, exact kills between frames, or offscreen map occupancy.

Current 1Hz capture works, but the hybrid benchmark is not a runtime upgrade and detection is not qualified.
- For future changes, run old and new regression fixtures, measure actual capture/encode interval, dropped frames, bytes/hr, OCR recall and precision by field, template/actor/landmark detection and replay consistency.
