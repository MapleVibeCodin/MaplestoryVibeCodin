Base: Javipen/maple-exp-overlay at 1a25186943a42fccd89eec2e0777c7b41ea5a21f, MIT (upstream LICENSE retained in the installed folder; derived from beanguri). Uses its existing passive screen capture, game-font EXP and wallet recognition, message deduplication, pickup OCR and click-through HUD; existing local-only network guard stays. No modification to FM Rush or other trackers. Separate LocalAppData folder MapleCashOverlayV1, no migration from other installed apps. No uploads to MCWO or Minerva. Hotkeys disabled initially to avoid clashes; use Start/Pause and Reset in main window. Existing HUD is simplified, repot row off by default.

New cash overlay extension shows observed raw pickup mesos/hr, raw plus known NPC-value/hr, observed pickups total and separate confirmed wallet change. Not actual realized net profit. Rate only after 60 active seconds, blank until pickup messages seen. Unknown price counts logged; * indicates unpriced units. No guess from closed inventory or FM valuation; known NPC prices from previous source research; item names matched exactly case-insensitively. Prepaid supplies not subtracted in gross display; wallet changes do not prove cash-only profit. CSV per-segment cumulative snapshots every 30s and before resets/map changes/close. Do not sum cumulative rows; use final row per segment. Captures with hidden map, pause, town or delayed pickup batch excluded. Map transitions are OCR-dependent; events near transition can be missed/misattributed. Partial/missed OCR possible; observed counts not guaranteed full pickup income. No false accuracy claim. Base full GUI and local log also available. Optional rank_maps.py reads saved MCWO JSON archive (not production backend); cap and contributor caveats unchanged.

Installer downloads immutable upstream source, retains LICENSE and assets, installs dependencies in own venv, patches three HUD captions only with exact anchor checks, compiles files, runs 5 isolated cash-core regression tests before launching; creates Desktop shortcut. It does not test live game OCR or upstream GUI. Requires Windows Python 3 and internet for setup; Tesseract installed separately for map names and unknown item OCR if absent. Local only after setup. No executable bundled. Installer not executed here. No all-99-engine merge: separate architectures and unknown licenses not copied. Minerva/msxp algorithms not ported; video OCR, automated vendor transaction detection and independent cash-specific public server ranking remain future work. No full video processing in v1.
