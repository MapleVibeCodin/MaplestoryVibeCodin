I’ll include a one-paste PowerShell update command with future FM Rush downloads.

For **v24.47**, extract the ZIP into Downloads, then paste this into **PowerShell**. It checks that the new launcher exists, closes running FM Rush copies launched from your extracted Downloads folders, moves the previous **v24.46** folder to the Recycle Bin, and starts the new version.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $downloads = Join-Path $env:USERPROFILE 'Downloads'
    $new = Join-Path $downloads 'MaplestoryVibeCodin-9206923b4979fe0c31d001093fde018b33a1eabc'
    $old = Join-Path $downloads 'MaplestoryVibeCodin-54d3700166deceafb8fb8acfc41ed8cfd7be17cc'
    $launcher = Join-Path $new 'Scanner Nov 20\START_FM_RUSH.bat'

    if (-not (Test-Path -LiteralPath $launcher -PathType Leaf)) {
        throw "Extract v24.47 to $new first."
    }

    $pattern = [regex]::Escape("$downloads\MaplestoryVibeCodin-") +
        '[0-9a-f]{40}\\Scanner Nov 20\\fm_rush\.py(?:"|\s|$)'

    $running = Get-CimInstance Win32_Process -Filter "Name = 'python.exe' OR Name = 'pythonw.exe'" |
        Where-Object { $_.CommandLine -match $pattern }

    foreach ($instance in $running) {
        $process = Get-Process -Id $instance.ProcessId -ErrorAction SilentlyContinue
        if (-not $process -or $process.HasExited) { continue }
        if ($process.CloseMainWindow() -and $process.WaitForExit(2000)) { continue }
        if (-not $process.HasExited) {
            Stop-Process -InputObject $process
            if (-not $process.WaitForExit(3000)) { throw 'FM Rush is still running.' }
        }
    }

    if (Test-Path -LiteralPath $old -PathType Container) {
        Add-Type -AssemblyName Microsoft.VisualBasic
        [Microsoft.VisualBasic.FileIO.FileSystem]::DeleteDirectory(
            $old, 'OnlyErrorDialogs', 'SendToRecycleBin'
        )
    }

    Start-Process -FilePath $launcher -WorkingDirectory (Split-Path -Parent $launcher)
}
```

If Brave loaded its unpacked extension from the **v24.46** folder specifically, load it from the new folder before running the command.
