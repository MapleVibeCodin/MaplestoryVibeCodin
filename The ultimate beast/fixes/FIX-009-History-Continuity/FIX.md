# FIX-009-History-Continuity: Repeated work, lost context or overwritten history

Status: **Policy implemented**

Before every project turn read AGENTS.md, NEXT-CHAT.md, this registry and relevant issue folders; use existing root cause, correction, evidence and tests before investigation. Every new failure gets a stable ID or updates matching existing record. Preserve runtime history and raw evidence locally, checkpoint request before edits and result after, verify readback. Do not mark unresolved issues fixed. Link all regression checks and update index; no duplicate issue for identical cause. No claim of account-memory write or future flawless compliance.

Update this record with each recurrence, actual check results, and the new commit. Never overwrite historical evidence.
