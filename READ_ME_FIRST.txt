FM RUSH v24.26 — LIVE MAP + HARD CHASE LOCK (extension 24.26.0)

Extract the whole ZIP. Run START_FM_RUSH.bat.
In brave://extensions, replace the old extension with browser_extension from this folder.
Reload HeneFM once. Keep HeneFM sorted Most recently seen.

LIVE: The first available HeneFM card immediately updates the item, seller,
channel, highlighted FM portal, and name finder. The FM map opens automatically.
CHASE: Locks that listing. Incoming cards, page refreshes and disappearing
listings cannot replace its seller or destination. Another CHASE cannot steal it.
UNLOCK: Returns immediately to the newest available card. Use UNLOCK on the
map, compact strip, or HeneFM card. Locked targets remain searchable off-page.
Skipping/buying clears the completed target, but a locked session stays locked
until UNLOCK; SKIP never logs a purchase. Ctrl+Alt+F retries the name finder.
Website filters control the feed; there is no extra browser profit threshold.

First launch installs Python 3.12 if needed and downloads dependencies.
Keep all assets in place. Existing purchase records are reused from
%LOCALAPPDATA%\FM_Rush\archives. To preserve preferences copy config.json
from the old folder before launching. Keep the old folder until records check out.
Automatic screenshots remain off by default. No automatic game inputs.
State-transition tests pass; live Windows capture/display timing not tested here.
